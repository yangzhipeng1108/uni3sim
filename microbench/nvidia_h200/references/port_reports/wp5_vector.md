## Derivations and notes

- A: A800 rule unchanged (trials 0-1 train, trial 2 validates). Resident CTA limits 8 (256 threads) / 2 (1024 threads) follow from the H200 ptxas usage (24 registers, 168 B) and H200 SM limits, identical to A800. Validation on trial 2: MAPE 5.88 %, max APE 15.03 % (gates 10 % / 30 %). The A800 `report.json` named in the yaml does not exist locally, so the H200 reference uses the reporter's schema and is the only reference file.
- B: A800 value 249.125 cycles (1.14e9/249.125); H200 215.266 cycles in both independent processes (0 % spread).
- C: grids 108/216/256/1024 became 132/264/313/1056; 313 = round(256 x 132/108) keeps the held-out cell at 2.37 CTAs/SM (observed min/max CTAs/SM 2/3). Queued divisor is ceil(1056/132) - 2 = 6. Within-run IQR spread max 0.0125, cross-run 0.0087, held-out rotation 2 mean/max APE 0.54 % / 3.50 % (gate 10 %). Registers: source 22, control 16 (A800 21 / 14).
- E1: one H200 process per hidden width, as the A800 per-width runners. Owner copies derive from the exact A800 capture sources: H2048 from `git show fc2c2dbb`, H4096 and H8192 from the A800 capture `source_snapshot/` (the tracked A800 files have since grown out-of-scope cells), H5120 from the tracked file. The A800 H2560 source is not retained anywhere; since all retained width probes differ only in `kHiddenSize`, derived static_asserts, kernel name and grid list, H2560 was reconstructed from the H2048 source with `kHiddenSize = 2560` (header states this). All cells pass the 10 % trial-spread gate; every row reports 32 registers / 168 B / 2 resident CTAs and one CTA per active SM. Observation: at H2048 the grid-1 add_square cell (669 cycles, identical in all three trials) is slower than grids 4 and 16 (514 / 520 cycles); it is reported as measured.
- E1 key rename: the 10 yaml keys `bf16_*_first_*_active108_block1024` hold the H200 grid-132 value; the reference's `yaml_key_rename_needed` maps each to `_active132`. The maintainer decides whether to rename.
- F: five trials of first (132 CTAs) and resident (1056 CTAs) cells, 512 rounds, `%globaltimer`; `kMaximumGridBlocks` raised 1024 -> 1252 so the 1056-CTA cell fits the buffers. Two independent processes agree within 1.0 % (first run 138.06 / 328.38 / 120.88 / 247.60 ns, published r2 run in the table).
- G: first/resident pair = median of five samples / 8192 rounds and (resident - first) / (7 x 8192); rate = 2e9 / pair ns. Maximum cross-sample spread 8.3 % (add_square tail-128 first cell). On H200 the scale_multiply resident pair increments (211 / 269 ns) are close to or below the first-pair latency (224 / 227 ns); reported as measured.
- H: see table. The owner-copy probe compiles on H200 with the A800 resource signature (24 registers, 168 B, 2 CTAs/SM). No timing-based substitute is used because the A800 parameter is defined by L2 byte counters.
- Source choice: the Add-RMSNorm and SiLU probes keep the vLLM 0.11.0 source-exact loops/expressions of the A800 probes (same probe), not vLLM 0.24 sources.
