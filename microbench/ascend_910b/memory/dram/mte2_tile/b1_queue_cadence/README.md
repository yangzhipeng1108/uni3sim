# GroupedMatmul B1 queue cadence

This independent Ascend 910B AIC benchmark measures a `256×256` (`stepKb=4`, `baseK=64`, `baseN=256`) GM-to-B1 fill with physical row stride, the `MTE2_MTE1` completion edge, and the corresponding four-K B1-to-L0B load. Two B1 and two L0B slots model `depthB1=8` and `dbL0B=2`. Modes `0` and `1` are the B-only controls: mode `0` uses one `Nd2NzParams` fill, while mode `1` emits CANN BF16 `CopyND2NZOnTheFly`'s 16 width-C0 source copy instructions. Modes `2` and `3` use those same respective B1 fills, then run four `16×256×64` MMADs through source-visible B1, L0B, L0A, and Cube ping-pong events. Their A tile is prefetched before timing and their C tile is never stored, so they remain B-ingress primitives rather than production FusedMoE code.

The target cell uses a 6144-element physical B row stride and 24 AICs. The host computes per-AIC timing from a 1×/4× differential and validates that every AIC completes every requested B group. It uses disjoint source groups within the supplied footprint and does not consume any production-kernel duration.

For the 8 GiB, 512-group cell, three fresh mode-0 captures have a `2297.331 ns` median completion per B1 group and three mode-1 captures have a `7081.875 ns` median. The `4784.544 ns` difference is therefore stable evidence of the real source issue cadence, rather than a missing queue-topology event. The matching three fresh mode-2/mode-3 captures have medians of `2301.510 ns` and `7080.365 ns`; their paired source-issue difference is `4781.263 ns`, with a `0.137%` max-span/median. Thus the B1-to-L0B-to-Cube handoff does not make the cadence a serially composable Forward service. Charging it per B1 group would still raise the exact `TOK2/E8/TOPK2/H6144/INT16384` W1 prediction from `1.022966 ms` to `2.860231 ms`, well beyond its `1.189697 ms` profiler task time. A future Forward mechanism must instead establish the production critical path that overlaps or amortizes this cadence; neither this difference nor a residual may be added to Forward.
