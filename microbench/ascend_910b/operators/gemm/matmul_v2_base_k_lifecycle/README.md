# MatMulV2 base-K lifecycle

This independent CANN 8.5.1 mechanism microbenchmark isolates the finite worker-local lifecycle caused by the MatmulImpl base-K loop. It does not invoke a production MatMulV2 operator or reproduce a production GEMM shape.

Twenty-four AIC workers each execute two identical BF16 `96 x 128 x K` output tiles with static no-tail configuration. The sweep changes `baseK` over `{32,64,128}` while preserving a 512-element A1 descriptor, a 256-element B1 descriptor, two A1/B1 buffers, the total semantic work, worker population, and output order. K is swept over `{1024,2048,4096}` so the difference can be attributed to the source-visible `K/baseK` loop count rather than a production shape. The program timestamp ends after `PIPE_ALL`, thereby retaining Scalar scheduling, MTE2/MTE1/Cube dependencies and final drain while excluding operator launch selection, multi-worker output partitioning, and production workload duration.

`matmul_v2_output_tile_lifecycle` is a separate boundary-credit probe. It uses a static BF16 `128 x {112,128} x K` output tile, base-K 128, 256-wide A1/B1 descriptors, and double-buffered A1/B1/L0 operands. It sweeps independent K values `{1024,2048,4096}`, output-tile counts `{1,2,4,6,9}`, and active AIC populations `{22,24}`. The continuous mode has only the terminal `PIPE_ALL`; the explicit-drain control inserts `PIPE_ALL` after every tile. Comparing their marginal output-tile costs determines whether `MatmulImpl` retains producer/consumer credits across source output boundaries. Neither complete program duration is a Forward parameter: only a source-defined continuity or drain conclusion, corroborated by the output-tile sweep, may constrain the analytical recurrence.

Build the probe in the agreed 910B container with `source /usr/local/Ascend/cann-8.5.1/set_env.sh`, `cmake -S . -B build -DASCEND_HOME_PATH=/usr/local/Ascend/cann-8.5.1 -DSOC_VERSION=Ascend910B2`, and `cmake --build build -j8`. Run it on an explicitly remapped idle device with `ASCEND_RT_VISIBLE_DEVICES=<physical-device> ASCEND_DEVICE_ID=0 ./build/matmul_v2_output_tile_lifecycle --base-n <112|128> --workers <22|24> --k <1024|2048|4096> --output-tiles <1|2|4|6|9> --force-tile-drain <0|1>`.
