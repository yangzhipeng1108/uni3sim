# Narrow MatMulV2 Scalar control

This independent CANN 8.5.1 mechanism probe targets the shared 16x224x64, 23-AIC, A1=1/B1=2 persistent MatMulV2 source program used by the B={1,2,4,8,16}, M=1, K=1536, N=5120 tail cluster. It compares static M=16 and dynamic-tail M=1 programs at K={768,1536} to attempt to separate source Scalar base-K and tail-control deltas. Whole-program durations remain diagnostic inputs only: the endpoints also contain MTE2, MTE1, Cube, and FixPipe work, so no Forward service may consume them unless an independent source-matched control span makes the Scalar component identifiable.

`matmul_v2_full_a_scalar_control_*` is a distinct 24-AIC, 16x176x64, A1=1/B1=2 full-A topology for the K={2048,4096} narrow-M family. It compares the same dynamic M=1 and static M=16 branches. The target K4096 source has one complete A1 descriptor and sixteen B1 descriptors; the K2048 endpoint preserves that full-A topology at a shorter source extent. `matmul_v2_full_a_five_n_scalar_control_*` preserves the separate 23-AIC, 16x256x64, A1=1/B1=2 topology with five local N tiles, exactly matching the full-A replay/control structure of the K8192 tail family while keeping K={2048,4096}. Both are Scalar-control discriminators only, not production-duration proxies. Capture each mode/K endpoint with `msprof op PipeUtilization`, then use `matmul_v2_full_a_scalar_control_report.py --topology {one_n|five_n}`; the reporter fail-closes on an unexpected kernel name, physical device, worker population, CSV schema, launch count, source snapshot, reused profiler log, or raw location, and it intentionally parses only AIC Scalar-pipe values.

For five-N captures use `matmul_v2_full_a_five_n_scalar_pipe_capture_runner.py` once per `{dynamic_m1,static_m16}×{2048,4096}` endpoint. It profiles exactly three post-warmup launches, writes raw profiler output only under `profiler_output/microbench/ascend_910b/`, and emits a source- and binary-bound manifest. The five-N report requires that manifest, so manually assembled or cross-endpoint profiler directories are rejected.

`microbench/ascend_910b/references/aic_matmul_v2_full_a_dynamic_m_n_major_control_source_cann_8_5_1.json` fixes the duration-free CANN source basis for the five-N hypothesis: `SetSingleShape` configures loop state once, while the N-major scheduler restarts the M loop at every local N tile. It establishes a candidate control placement but no time parameter; the PipeUtilization capture remains mandatory before any Forward change.
