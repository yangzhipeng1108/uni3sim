# MoeComputeExpertTokens key-1003 phase probes

These standalone CANN 8.5.1 probes isolate two source mechanisms from `MoeComputeExpertTokens` key 1003. `compute_expert_tokens_scatter_mte3` measures one UB-to-GM `DataCopyPad` request with byte-valued `blockLen=4`, variable `blockCount`, zero source/destination stride, and its terminal `MTE3_S` completion edge. `compute_expert_tokens_sync_phase` measures the exact int32 `InitOutput` followed by `SyncAll` sequence in the production 1-AIC:2-AIV mixed-task topology at 48 AIVs. Both exclude the production search, reduction, input, complete operator payload, and production/evaluation duration.

`compute_expert_tokens_ss_init_sync_phase` separately measures the key-1001 `Int32SS` initialization phase: only AIV worker zero initializes the one shared `numOfExpert` int32 output, then all 48 AIV workers execute `SyncAll`. It deliberately excludes the key-1001 CopyIn, vector Compare/Select/Reduce loop, atomic CopyOut, task launch, and all production/evaluation duration.

Configure and build inside the prescribed 910B container with `cmake -S . -B build -DASCEND_HOME_PATH=/usr/local/Ascend/cann-8.5.1 -DSOC_VERSION=Ascend910B2 -DCMAKE_BUILD_TYPE=Release` followed by `cmake --build build -j1`. Select one idle physical device with `ASCEND_RT_VISIBLE_DEVICES`, then run `compute_expert_tokens_scatter_mte3 BLOCK_COUNT ITERATIONS` or `compute_expert_tokens_sync_phase ELEMENTS_PER_WORKER ITERATIONS`. The host programs remap that selected device to logical device zero.

The key-1003 E512 source executes two scatter requests with `blockCount=256` and `blockLen=4`. Its first initialization uses 512 int32 elements per AIV, while `SyncAllCore` uses eight int32 elements per AIV. Results are valid only for those exact source geometries and must be composed in source order with the separately priced search and `ProcessAfter` mechanisms. The key-1001 program instead initializes its shared output from worker zero then synchronizes all 48 AIVs; run `compute_expert_tokens_ss_init_sync_phase EXPERTS ITERATIONS` only for its source-defined 1..256-expert domain.
